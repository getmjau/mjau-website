### Commands in mjau.yaml

The following commands can be used in the `pre_commands` and `commands` sections of a request:

- `echo`: Prints a message to the console.
- `add_variable`: Adds a new variable or updates an existing one.
- `add_json_variable`: Extracts a value from a JSON response and stores it in a variable. The path uses GJSON path syntax. For more information, see the [GJSON Path Syntax documentation](https://github.com/tidwall/gjson/blob/master/SYNTAX.md).
